Dairy Sales Analytics & Inventory Prediction

About:

A Streamlit-based application for analyzing dairy sales data, visualizing product demand and predicting sales for the next 30 days.

Features:

- Upload dairy sales CSV
- Product, location and date filters
- Sales trend visualization
- Product demand analysis
- 30-day sales prediction
- Inventory suggestion with 10% safety stock

Technologies used:

- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Linear Regression

Run the Project:

pip install streamlit pandas numpy matplotlib scikit-learn
streamlit run app.py
